# Sialy Desktop — Windows releases

Офіційні інсталяційні пакети Sialy Desktop для Windows. Це сховище випусків лаунчера; воно не містить користувацьких профілів або ключів.

## Встановлення

1. У розділі **Releases** завантажте `Sialy-Setup-5.6.2.exe` та запустіть його з диска D.
2. Натисніть **Встановити Sialy** або **Оновити Sialy**. Власні компоненти й дані встановлюються в `D:\Sialy`; розпаковувати ZIP не потрібно.
3. Дочекайтеся підсумку й виконайте показані додаткові кроки, якщо Lively або браузер потребують вашої дії.

Починаючи з 5.6.0, наступні випуски можна отримувати безпосередньо в лаунчері: **Система → Перевірити оновлення → Завантажити й оновити**. Завантаження починається після натискання; перевірений пакет автоматично запускає встановлення зі збереженням розпізнаних налаштувань. Стара версія до 5.6.0 потребує одного початкового ручного встановлення цього випуску.

Поточний випуск 5.6.2 виправляє розпізнавання стандартного RunLevel у завданнях автозапуску Windows, додає сучасні налаштування сумісності TLS та точніші повідомлення про мережеві помилки. Якщо перевірка оновлення у старому лаунчері не працює, завантажте EXE цього випуску вручну.

## Можливості

- Локальний неоновий лаунчер, запуск і відновлення компонентів, діагностика й автозапуск.
- Анімовані шпалери Sialy через Lively Wallpaper та чотири смуги Music Only.
- Спільний профіль налаштувань, живе й демонстраційне прев’ю еквалайзера.
- Music Sources для вибраних програм та підключення вкладки через Sialy Music Tab.
- CPU/GPU та температура CPU за наявності відповідного джерела даних.

Власні дані Sialy зберігаються на D. Windows, браузер і спільні Lively/WebView2 можуть використовувати системні папки. Повторне захоплення вкладки Opera може потребувати натискання в розширенні.

Кожен випуск містить EXE, SHA-256 і `sialy-update.json` для лаунчера. Контрольна сума перевіряє цілісність пакета; вона не є цифровим підписом видавця Windows.
