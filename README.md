# Sialy Desktop — Windows releases

Офіційні інсталяційні пакети Sialy Desktop для Windows. Це сховище випусків лаунчера; воно не містить користувацьких профілів або ключів.

## Встановлення

1. У розділі **[Releases](https://github.com/LuNocraf/Sialy-Desktop-Releases/releases/latest)** завантажте `Sialy-Setup-5.6.5.exe` та запустіть його.
2. Для першого встановлення виберіть окрему папку кнопкою **«Обрати папку…»** або введіть шлях. Підтримуються локальні диски NTFS/ReFS, пробіли й українські літери в назвах. Диск D не обов’язковий.
3. Перевірте показаний шлях і натисніть **Встановити Sialy**. Наявну інсталяцію інсталятор оновлює в її поточній папці; під час оновлення вибір папки заблокований.
4. Дочекайтеся підсумку й виконайте показані додаткові кроки, якщо Lively або браузер потребують вашої дії. Розпаковувати ZIP не потрібно.

Починаючи з 5.6.0, наступні випуски можна отримувати безпосередньо в лаунчері: **Система → Перевірити оновлення → Завантажити й оновити**. Завантаження починається після натискання; перевірений пакет автоматично запускає встановлення зі збереженням розпізнаних налаштувань. Стара версія до 5.6.0 потребує одного початкового ручного встановлення цього випуску.

Поточний випуск **5.6.5** додає вибір папки для нового встановлення. За наявності відповідного диска D пропонується `D:\Sialy`; інакше — `%LOCALAPPDATA%\Programs\Sialy`. Повний шлях видно до встановлення й можна змінити. Оновлення та відновлення зберігають поточну папку й профіль. Перенесення вже встановленої програми на інший диск у цьому випуску не виконується. Якщо вибраний диск недоступний, програма зупиняється з повідомленням і не переходить до іншої папки.

Включено виправлення локального з’єднання з 5.6.4: інсталятор більше не утримує порт попереднього лаунчера. Чистий запуск підтримує перехід зі старих версій, зокрема 5.6.2.

Включено оформлення 5.6.3: фірмові панелі керування лаунчера, Music Sources і вибору програми, рубіновий неон та виправлені відступи Music Only. Налаштування музики й шпалери зберігаються. Якщо старий лаунчер не відкривається, завантажте EXE вручну.

## Можливості

- Локальний неоновий лаунчер, запуск і відновлення компонентів, діагностика й автозапуск.
- Анімовані шпалери Sialy через Lively Wallpaper та чотири смуги Music Only.
- Спільний профіль налаштувань, живе й демонстраційне прев’ю еквалайзера.
- Music Sources для вибраних програм та підключення вкладки через Sialy Music Tab.
- CPU/GPU та температура CPU за наявності відповідного джерела даних.

Власні компоненти, профіль, кеш оновлень, журнали й тимчасові файли Sialy зберігаються у вибраній папці. Windows, браузер і спільні Lively/WebView2 можуть використовувати системні папки. Повторне захоплення вкладки Opera може потребувати натискання в розширенні.

Кожен випуск містить EXE, SHA-256 і `sialy-update.json` для лаунчера. Контрольна сума перевіряє цілісність пакета; вона не є цифровим підписом видавця Windows.
